# B8A1 – Assignment: Problem Solving with TypeScript & OOP

## Assignment Overview

This assignment is based on the core concepts of TypeScript.

The coding part includes 8 problems covering basic types, optional parameters, union types, readonly tuples, generics, interfaces, type narrowing, Promises, and Object-Oriented Programming (OOP).

All coding solutions are implemented in a single TypeScript file named `solutions.ts`, following the given assignment requirements.
